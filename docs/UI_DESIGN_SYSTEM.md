# GramVoice TN — Civic Design System & UI Specification

## 1. Design Philosophy
- **Light-First & Calm**: Light civic interface inspiring trust, transparency, and ease of use.
- **Human & Accessible**: Plain Tamil and English microcopy, 44px+ minimum touch targets, high contrast ratios (WCAG AAA for text).
- **Subordinate AI**: AI summaries and transcriptions are labeled clearly with "AI-Assisted" tags and never confused with official constitutional decisions.

## 2. Design Tokens
- **Background Primary**: `#F8FAFC` (Slate-50)
- **Surface**: `#FFFFFF` (Pure White)
- **Surface Secondary**: `#F1F5F9` (Slate-100)
- **Border**: `#E2E8F0` (Slate-200)
- **Text Primary**: `#0F172A` (Slate-900)
- **Text Secondary**: `#475569` (Slate-600)
- **Text Muted**: `#64748B` (Slate-500)
- **Civic Primary (TN Govt Green)**: `#0D7A46` / `#059669` (Emerald-700 / Emerald-600)
- **Govt Accent (Administrative Indigo)**: `#1E3A8A` / `#2563EB` (Blue-900 / Blue-600)
- **Status Success**: `#16A34A` (Green-600)
- **Status Warning / Alert**: `#D97706` (Amber-600)
- **Status Danger / Breach**: `#DC2626` (Red-600)
- **Status Info**: `#0284C7` (Sky-600)

## 3. Typography Hierarchy
- **Tamil Font Stack**: `Noto Sans Tamil`, `Mukta Malar`, `-apple-system`, `sans-serif`
- **English Font Stack**: `Inter`, `system-ui`, `sans-serif`
- **Line Heights**: `1.6` for Tamil body copy to prevent glyph clipping.
- **Sizes**:
  - Display: `24px` / `30px` bold
  - Page Title: `20px` / `26px` semibold
  - Section Title: `16px` / `22px` semibold
  - Body: `14px` / `22px` regular
  - Caption: `12px` / `16px` medium

## 4. Spacing Scale & Touch Targets
- Base Grid: `4px`, `8px`, `12px`, `16px`, `24px`, `32px`
- Minimum Citizen Interactive Touch Target: `44px x 44px`
- Voice Recording Button: `72px x 72px` circle with pulsing recording wave animation
