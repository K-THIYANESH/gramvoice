# GramVoice TN — UI Redesign Summary

## 1. Citizen Mobile-First Experience
- **Fluid Layout**: Optimized for 360px, 390px, and 430px viewports with single-column touch cards.
- **Microcopy**: Changed all ambiguous technical jargon into clear human questions:
  - "Submit Response" → "Tell us what you think about this project" / "இத்திட்டம் பற்றி உங்கள் கருத்தை பகிருங்கள்"
  - "Upload Evidence" → "Take a photo of the problem" / "பிரச்சனையை புகைப்படம் எடுத்து பதிவேற்றவும்"
- **Project Civic Journey**: Visual 6-stage stepper (Discover → Understand → Suggest → Participate → Validate → Monitor → Maintain).

## 2. Government Desktop-First Experience
- **Command Dashboard**: High-density triage table with urgency badges, countdown timers, CEI meters, and one-click actions.
- **Cryptographic Decision Ledger Console**: Interactive block explorer with SHA-256 validation status, previous hash verification, and live tamper simulation tool.
- **Document AI & DPR Portal**: Multilingual summary generator with budget line item decomposition.
- **Gram Sabha Synthesis Console**: AI clustering of spoken submissions into structured priority agenda items.
