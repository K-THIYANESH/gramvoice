2. **Voice AI Pipeline**: Live microphone capture with Web Audio API, Gemini 3.7 Flash transcription, and Tamil/English transcript verification.
3. **Cryptographic Ledger**: SHA-256 block chain verification with tamper-resistance test suite.
4. **CEI Engine**: Multi-pillar formula calculating Voter Participation, Ward Diversity, Voice Adoption, Resolution Responsiveness, and Quorum Attainment.

6. **Offline Sync Engine**: Client-side storage queue supporting Online, Offline, Saving, Queued, Syncing, Synced, and Sync Failed states.
7. **Public Transparency Portal**: Open access without login, sanitized data, budget explorer.
